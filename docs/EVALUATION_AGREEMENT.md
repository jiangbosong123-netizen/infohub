# 人工相关性标注一致性

`app.evaluation_agreement` 对**已经完成的两份独立人工相关性标注**计算 Cohen κ。输入是只读的、已通过 `validate_evaluation_dataset` 校验的私有数据集；不读取原文，不修改标注，也不把第三人的裁定标签当作任一审核者的意见。

```bash
python -m app.evaluation_agreement \
  --dataset /path/to/private/dataset \
  --reviewer-a reviewer-id-a \
  --reviewer-b reviewer-id-b
```

正式盲测请加 `--split test`，只用盲测集计算 κ，避免训练/开发集掩盖盲测分歧。
输出的 `scope_split` 和 `dataset_cases` 明确本次范围与分母。

必须指定同一对真实审核者。只纳入该两人均对同一固定内容散列完成独立标注的案例，不混合其他审核者组合。输出包括配对数、分割/语言覆盖、三个类别的混淆矩阵、观察一致率、偶然一致率和 κ。`unknown` 是独立类别。若没有配对案例，指标为 `null`；若两人所有标注都落在同一个类别，κ 因分母为零而为 `null`。不足 30 个配对案例时仅供流程检查，不可作为质量门槛。即使 κ 达到正式 SPEC 的 0.70 参考线，也还须检查各关键切片、数据集规模、盲测隔离、裁定与模型表现，不能仅凭此报告宣称 NLP 已通过验收。

当前仓库只有合成测试身份和流程样本；实际候选数据尚无人工标注。这一工具尚未产生真实的一致性结论，也无法自行证明审核者身份或标注独立性。完整聚合报告可能显示审核者 ID；只应在受限环境查看，不要把真实私有报告提交到仓库。
